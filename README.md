# Pocket Phone 0.9.9 — SillyTavern compatibility mirror

This repository fixes the upstream extension's stale version metadata and restores its normal-generation interceptor. The upstream code identifies itself as **Pocket Phone 0.9.9**, while its original `manifest.json` still declares **0.9.6**.

## Install in SillyTavern

Open **Extensions → Install Extension**, then paste:

```text
https://github.com/DesZiDesu/Pocket-Phone
```

After installation or update, reload SillyTavern. The Extensions panel should show **Pocket Phone 0.9.9**.

## Lorebook integration

Download and import:

- [`Pocket-Phone-Lorebook.json`](./Pocket-Phone-Lorebook.json)
- [Setup and command reference](./LOREBOOK.md)

In SillyTavern, open **World Info / Lorebooks → Import World Info**, select the JSON file, and enable the imported book globally or for the relevant character/chat.

Then open **Pocket Phone → Settings → Shared Universe** and enable:

- **Bot/NPC cross-chat**
- **Affects main roleplay**
- **Bot can call automatically**

The bridge can convert ordinary SillyTavern responses into incoming Pocket Phone texts, new NPC chats, calls, voice messages, stickers, locations, status notes, polls, gifts, contact cards, payments, earnings, and follows. It also preserves continuity for Action Log events, calls, wallet state, feed/story activity, groups, privacy settings, and supplied period/health context.

## Implementation

The local manifest is version `0.9.9` and declares Pocket Phone's `ppGenInterceptor`. The JavaScript and stylesheet are loaded from the exact upstream snapshot at commit:

```text
f22ed2fcced366031b6f88271db921ebcf007d32
```

The local loader installs an additional normal-roleplay parser for the Lorebook's extended event commands. The pinned upstream source remains:

```text
https://github.com/janzanaja188-cyber/pocket-phone
```

The upstream commit is pinned, so this mirror will not silently change when upstream `main` changes. An internet connection is required when SillyTavern loads the extension because the pinned files are delivered through jsDelivr.

## Limits

Lorebook instructions guide the language model but do not guarantee model compliance. Incoming events occur after an ordinary SillyTavern assistant generation; they are not generated by a background timer while the chat is idle. Image messages require actual uploaded media and therefore cannot be created from Lorebook text alone.
